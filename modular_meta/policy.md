# Преамбула

Эти политики могут и будут использоваться мейнтейнерами для закрытия или мержа ваших пулл-реквестов. Никаких гарантий

## ИИ-генерации: (‼Important‼)
Когда мы допускаем ИИ-ассистирование, например, для поиска ошибок, решения проблем, нахождения переменных, получения сниппетов кода и, даже, написания интерфейсов в большинстве случаев (не их рефактора/переделки), мы не одобряем очевидное использование ИИ-генерации в случаях, где вы, будучи разработчиком перекладываете свои умственные усилия до минимального `` git add . `` и ``git commit && git push ``; Мы (мейнтейнеры) различаем допустимую меру получения кода с помощью ИИ,  Не пытайтесь скрыть использование генеративного-ИИ, **лучше сами укажите это в специальной графе Генеративный-ИИ (см. Pull Request template)**. Эта политика установлена и применяется начиная с даты мержа этого пулл-реквеста. Не распространяется на сторонние сервисы/репозитории, используемые игровыми серверами.

❗ Под ручным вкладом не подразумевается мнимый вклад [инженера-архитектора](https://youtu.be/iOVFZ5mconE) ❗

❗❗ **Рефакторы с помощью ИИ строго под запретом** ❗❗

## Названия и наполнение пулл-реквестов.
Нашим стандартом является название пулл-реквестов на английском языке, тело пулл-реквеста может оставаться на русском.

## Комментарии
**Мы допускаем использование комментариев внутри кода с помощью** ``/* Hello, LummoxJR! */`` **и/или** ``// todo: refactor this on 517``
Однако! Стоит подметить, что любые комментарии стоит размещать исключительно в английском языке. Форма написания комментариев - свободная, тем не менее, мы не можем
Используйте ``///`` **Тройной слэш** для написания документации или объяснения переменных, (**Пример: ```var/foobar``` /// Imagine this commentary is inside of a multi-line codeblock above the var**) если исходя из её названия невозможно понять, что именно она обозначает.

## Переменные
Форма написания свободная, **однако мейнтейнер в праве потребовать переименовать её, если она слишком длинная и/или мейнтейнер имеет достаточные основания на это требование (например, использование расистских слов, небрежных выражений и так далее.)**
