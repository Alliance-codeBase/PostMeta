# Module: autotranslate

**Module ID:** `autotranslate`

## Description

Система автоматического перевода чата (RU <-> EN) с интеграцией LibreTranslate и Runechat. Позволяет игрокам автоматически видеть перевод сообщений на лету, используя локальный или удаленный провайдер перевода. Включает кэширование переводов для снижения нагрузки на провайдер, настройки предпочтений для включения/отключения автоперевода, и бесшовное отображение переведенного текста в Runechat с сохранением оригинального форматирования (цвета, иконки, курсив).

## TGUI Files:

- Нет изменений в TGUI (вся логика отображения обрабатывается на стороне клиента через Runechat).

## Configuration

Настройки модуля находятся в `code/config.dm`:

- `TRANSLATE_HTTP_URL` — URL провайдера перевода (по умолчанию `http://127.0.0.1:5000` для локального LibreTranslate).
- `TRANSLATE_HTTP_TIMEOUT_SECONDS` — таймаут запроса к провайдеру (по умолчанию 5 секунд).
- `TRANSLATE_CACHE_SIZE` — размер кэша переводов (по умолчанию 5000 записей).

## Dependencies

- **LibreTranslate** (локальный или удаленный сервер) — для работы перевода необходим запущенный сервер LibreTranslate с загруженными моделями `ru-en` и `en-ru`.
- Для локального запуска на Windows используйте скрипты из папки `tools/autotranslate` (требуют Python 3.10+ и Docker или нативную установку).

## Notes

- Модуль полностью автономен и может быть отключен путем удаления строки `#include` в `main_modular_include.dm`.
- При первом запуске сервера SS13 происходит проверка доступности провайдера перевода. Если провайдер недоступен, автоперевод остается отключенным на весь раунд, не влияя на работу сервера.
- Кэш переводов хранится в памяти и сбрасывается при перезапуске сервера.
